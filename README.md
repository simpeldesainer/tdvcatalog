# The Design Vault — Catalogue & Services Web Suite

A modern, responsive, multi-page catalog and services portal designed for interior designers, architects, and material sourcing teams.

## Structure

- `index.html` — Main portal landing page with high-level section thumbnails
- `material.html` — Complete Material Catalog (Tiles, Stone, Glass, Metal, Wood, Leather, etc.)
- `product.html` — Product Catalogs (Furniture, Lighting, Doors & Windows, Sanitary)
- `service.html` — Design & Technical Services (Shopdrawings & 3D Visualization)
- `css/style.css` — Shared design system & styling
- `js/main.js` — Shared catalog rendering & modal logic

## How to Host on GitHub Pages

1. Push this repository to GitHub.
2. Go to **Settings** > **Pages**.
3. Select `main` branch and `/ (root)` folder.
4. Click **Save**.
